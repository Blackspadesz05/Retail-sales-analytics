# Retail Sales Analytics & Business Intelligence

## Project Overview
An end-to-end data analytics project exploring retail sales performance, product trends, customer behavior, and geographic performance to generate actionable business insights.

## Business Objectives
- Measure overall sales performance using key performance indicators (KPIs).
- Identify high-performing and low-performing product categories.
- Analyze sales by product, customer, state, and region.
- Explore monthly sales trends and growth.
- Build interactive dashboards to communicate findings.
- Provide data-driven business recommendations.

## Tools & Technologies
- MySQL
- Python
- Pandas
- Matplotlib
- Microsoft Excel
- Power BI
- Git and GitHub
